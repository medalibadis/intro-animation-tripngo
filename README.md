# TripnGo - Splash Screen & Brand Logo Animation

An ultra-premium 2.5-second mobile splash-screen logo animation and welcome screen experience for **TripnGo**, inspired by the signature motion design style of Zauri Miminoshvili.

## ✨ Features
- **Calligraphic Write-On Motion:** Dynamic synchronized stylus spark and letter-by-letter reveal (`T` → `r` → `i` → `p` → `n` → `G` → `o`).
- **Orbital Ribbon Flight:** Seamless transformation from logotype into an elegant Airplane following a continuous $C^1$ cubic Bézier flight loop with brand gradient trail (`#0090D9` → `#34D399` → `#F5B819`).
- **Harmonic Spring Settle:** Damped harmonic oscillation physics for a satisfying elastic pop & settle.
- **Interactive 3D Preview Chassis:** Realistic mobile chassis with 3D gyroscopic tilt, slow-motion controls (0.5x, 1.0x, 1.5x), and instant replay.
- **Modern Welcome Screen:** Smooth cross-fade transition into the flight booking UI.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Python 3
python3 -m http.server 3000

# Open in browser:
# http://localhost:3000
```
